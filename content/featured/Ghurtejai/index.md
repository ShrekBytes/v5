Full-stack travel platform for Bangladesh. Django REST Framework backend with modular apps, JWT auth, role-based access control (guest / user / moderator / admin), content moderation, voting, bookmarks, nested comments, and full-text search. Flutter mobile frontend. Deployed with Docker Compose + Nginx; Cloudflare R2 for media.
