Minimal self-hosted dashboard with a Go HTTP backend exposing modular REST endpoints for service monitoring, RSS aggregation, weather, bookmarks, and to-do. Multi-arch Docker images published automatically on every release tag. Ships with Docker Compose and Podman Quadlet configs — deployable in under 5 minutes.
